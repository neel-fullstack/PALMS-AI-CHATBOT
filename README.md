# PALMS AI Chatbot

## Overview

PALMS AI Chatbot is an AI-powered warehouse management assistant developed during my internship at Technoforte Software Pvt. Ltd.

The chatbot was designed to help users retrieve warehouse-related information through natural language interactions and AI-powered search capabilities.
