# PALMS AI Chatbot

## Overview
PALMS AI Chatbot is an AI-powered warehouse management assistant designed to provide intelligent responses and enterprise information retrieval.

## Features
- AI Agent Integration
- RAG Architecture
- Context-Aware Responses
- Warehouse Information Retrieval
- SQL-Based Data Access
- Natural Language Query Processing

## Tech Stack
- Python
- Streamlit
- .NET Web API
- SQL Server
- Ollama
- ChromaDB
- RAG

## Responsibilities
- Developed AI retrieval workflows
- Integrated AI Agents
- Improved chatbot response quality
- Designed enterprise knowledge retrieval system
